### Hardware & How Computers Work (Core 1 Domains 1 & 3)
**What to cover:**
*   CPU types (Intel vs AMD, x86 vs x64, cores, cache), sockets, thermal paste
*   RAM (DDR4, DDR5, ECC), dual-channel, slots
*   Storage: HDD (RPM) vs SSD (SATA, NVMe, M.2), RAID (0, 1, 5, 10)
*   Motherboard: BIOS/UEFI, CMOS battery, chipset, PCIe
*   PSU: wattage, connectors (24-pin ATX, SATA, PCIe)
*   Ports: USB (2.0/3.0/3.1/USB-C/Thunderbolt), HDMI, DisplayPort, VGA

**YouTube Theory:** [Professor Messer A+ Core 1 Sections 1 & 3](https://www.professormesser.com/free-a-plus-training/220-1201/220-1201-video/220-1201-training-course/) + Branch Education hardware deep-dives.

### Operating Systems — Windows & Linux (Core 2 Domain 1)
**What to cover (Windows):** Editions, NTFS permissions & inheritance, Registry (`HKLM`, `HKCU`), CLI tools (`ipconfig`, `ping`, `tracert`, `netstat`, `tasklist`, `sfc /scannow`), Task Manager, Event Viewer, Windows Firewall, UAC.

**What to cover (Linux):** Filesystem hierarchy (`/etc`, `/var/log`, `/home`), essential commands (`ls -la`, `grep`, `find`, `chmod`, `chown`, `ps aux`, `kill`, `top`, `apt`), octal permissions (755, 644, 700), users/groups (`adduser`, `passwd`, `sudo`, `/etc/shadow`).
